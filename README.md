## What I actually build

I run eduarddziak.com as an engineering project rather than a page builder. Static Astro site, deployed on Cloudflare Pages, with a system of AI agents that plan, write, review, and release every change. Each release gets a record and a rollback point. Nothing ships unless a check passes first.

Then I publish what it cost. There is a page on the site with the real figure, around $2,200 and 2.5 billion tokens across 17 working days, with the pricing sources named and the assumptions written out where I had to guess. Most people who talk about building with AI will not show you that part.

I write about using AI for marketing the same way. From the work, with the numbers attached, and with the bits that did not work left in.
